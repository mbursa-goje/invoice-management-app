# Invoice Management Application

A full-stack-ready Invoice Management System built with **React 19**, **Tailwind CSS v4**, and **TypeScript**. This application allows users to create, read, update, and delete invoices, with full theme support (Light/Dark modes) and a responsive design that matches Figma specifications.

![Design Preview](public/assets/preview.png)

## 🚀 Features

- **Full CRUD Functionality**: Create new invoices, edit existing ones, and delete with confirmation.
- **Dynamic Form**: Automatic total calculations as you add or remove items.
- **Light/Dark Mode**: Seamless theme switching using CSS variables.
- **Responsive Layout**: Custom-built for Mobile, Tablet, and Desktop.
- **Persistent State**: Invoices are saved to `localStorage` so your data persists after refreshing.
- **Status Filtering**: Filter your dashboard by Draft, Pending, or Paid status.
- **Premium UI**: Built with the "League Spartan" font and custom micro-animations.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4 (with custom CSS variables)
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **Language**: TypeScript

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mbursa-goje/invoice-management-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production

To create a production-ready bundle:
```bash
npm run build
```
